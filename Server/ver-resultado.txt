Para ver la página de estadísticas en tu ordenador:

1. Abre una terminal y entra en la carpeta Server.

2. La priemra vez, debes crear el entorno virtual:

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run app.py

3. Activa el entorno virtual y ejecuta la aplicación:
source .venv/bin/activate
streamlit run app.py

4. Se abrirá en el navegador; si no, visita http://localhost:8501. Desde allí podrás seleccionar varios JSON de partidos.
